---
description: Show where the hackathon stands - tasks in progress, open questions for the humans, blocked and finished work - from the shared GitHub board. Use when the user asks about progress or status in a hackathon kit repo.
---

> The `hack` command is on your PATH while this plugin is enabled. If the shell reports `hack: command not found`, run it as `node "${CLAUDE_PLUGIN_ROOT}/bin/hack"` instead, with the same arguments.

Run `hack status`. Summarize it for the user in the team language in a few lines: progress (done of total), who works on what, open questions that wait for their answer (with links, these need them), and anything blocked or stale. Don't repeat the whole board.
